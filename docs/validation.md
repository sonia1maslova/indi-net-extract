# 验证范围

版本：0.1.0.dev0。验证日期：2026-11-10。本页概述已完成的检查和仍未验证的范围；首次公开仓库不会自动增加已验证的平台或数据范围。

## 初版检查

- 54项单元及接口测试通过：批处理10项、提取数值12项、后处理和Dice 21项、保存/载入11项。
- 小型合成输入中，双回归串行和两进程结果一致；wheel中的两进程GIG-ICA、平滑、Top-N及结果保存/回读通过。
- 两组小型FSL双回归对照通过。连续与二值模板的β最大绝对差分别为1.0529613776733004e-6和1.190774973361397e-6。
- 分发名改为indi-net-extract后，独立目标目录安装、元数据、导入和小型并行检查通过；该次修改没有重跑上述全部54项检查或FSL。

## 独立GIG-ICA核心

已有11项核心检查、6组合成数据与未修改作者MATLAB核心的独立对照，以及原研究队列中预先选定的三名真实被试对照。真实被试连续成分的最低空间相关为0.997386、0.999585、0.999906，最大单成分相对误差为7.23%、2.88%、1.37%。结果接近，但没有全部达到严格数值等价标准。

MATLAB复算、白化及求解器诊断支持近零特征值的数值敏感性是差异来源之一，尚未证明它是唯一原因。不能只凭高相关或高Dice认定逐值一致，也不能把核心的历史验证当作封装后真实大样本的完整验证。

## 实际测试环境

Python 3.13.14；NumPy 2.2.6；SciPy 1.15.3；NiBabel 5.4.2；threadpoolctl 3.6.0。FSL独立对照使用6.0.4。MATLAB和FSL用于外部对照，不是工具运行依赖。

声明Python >=3.11不等于所有这些版本都已测试。其他Python/数值库组合、Windows原生多进程、真实大样本内存峰值和长时运行仍待验证。

## 在自己的环境复查

先安装运行依赖，再从仓库根目录执行：

```bash
python -m pip install .
python -m unittest discover -s tests -t . -v
```

本仓库的单元测试使用合成数据，不需要下载研究影像，不调用MATLAB或FSL。可选的外部对照脚本是tests/validate_distribution.py；它需要额外指定FSL位置，并使用新输出目录。
