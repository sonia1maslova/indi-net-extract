# 方法与数据约定

## 输入与方法分开

每名被试提供一份已准备好的4D静息态NIfTI。清洗、逐扫描标准化、拼接和配准由调用者完成。包只在共同mask内提取数据，并按各算法本身的要求中心化、白化或归一化。没有 `run_normalization` 或扫描拼接参数。

内部矩阵为BOLD `T×V`、模板 `V×K`、个体图 `V×K`、时间序列 `T×K`。mask内体素按NIfTI Fortran索引排列，并按同一顺序映射回图像。成分顺序从模板保留到输出，不自动匹配或翻转符号。

## 经典双回归

第一步以K张模板为共同解释变量，估计各成分随时间变化的系数；第二步以这些时间序列为共同解释变量，估计每个体素的成分β。

实现沿用项目已对照的经典路线：模板空间去均值及总体标准差缩放；输入整体时间去均值；第一步时间序列去均值并按样本标准差 `ddof=1` 归一化；第二步包含截距。该设置对应FSL `des_norm=1`。输出是连续β，不是统计Z；没有空间先验惩罚或时间点加权。

## GIG-ICA

采用现有独立NumPy/SciPy移植，保留作者算法的白化、阈值与回退、模板标准化、非高斯性和模板对应目标，以及迭代停止规则。默认使用已对照的SVD伪逆路线。没有另外加入跨成分正交约束。

输入加载使用临时memmap控制加载副本；白化和SVD仍需要内存，不能把该实现理解为完全在磁盘上运算。逐被试完成后保存结果，批次只返回状态和路径。

## 平滑与选取

平滑在连续图提取后、二值化前执行：`G(M*f)/G(M)`，保留原mask，高斯核截断4倍标准差。每个宽度从同一份原始连续图独立计算，只沿三个空间轴平滑。

固定Top-N按有限带符号值降序选取；零值、负值可以入选。并列时按原始Fortran体素索引排序。每成分必须选足N，N来自显式列表或固定二值参考在mask内的计数。

## 评价

精确Dice为 `2×交集体素数/(个体体素数+参考体素数)`。完整矩阵的行是个体成分，列是参考成分；对应分数取对角线。单侧为空为0，双侧为空为NaN，不能静默忽略无效成分后报告完整K成分均值。

`overlap_fraction` 是K张二值图的逐体素平均。固定mask、K和各成分N时，全mask平均值固定，因此不是有个体差异的总体指标。
